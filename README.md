# Tolpar Tea House

A responsive two-page website for a fictional tea house in Dhanmondi, Dhaka. Built for the Inovegen Internship Task 4 (Web Development, Front-End).

## Concept

Tolpar Tea House lets visitors browse the menu, time their tea with a brew timer and reserve a table online. The design uses a deep tea-green and marigold palette with Bricolage Grotesque as the single typeface.

## Pages

- `index.html`: hero with brew timer, filterable menu, visit details, FAQ
- `booking.html`: table booking form with live summary

## Features

1. Brew timer with progress ring, pause and reset
2. Menu filter by category plus live search
3. Accessible FAQ accordion
4. Light and dark theme toggle, remembered between visits
5. Booking form with live validation, error summary and confirmation
6. Live holding-fee calculator and guest stepper
7. Mobile menu, back-to-top button, character counter

## Technologies

HTML5, CSS3 (Grid, Flexbox, custom properties), vanilla JavaScript (ES6). No frameworks or build step.

## Accessibility

Semantic landmarks, skip link, labelled fields, `aria-live` feedback, visible focus rings, keyboard-friendly menu and accordion, reduced-motion support and readable contrast in both themes.

## Setup

1. Unzip the project.
2. Open the folder in VS Code.
3. Install the Live Server extension, right-click `index.html` and choose Open with Live Server.

You can also double-click `index.html` to open it in a browser.
